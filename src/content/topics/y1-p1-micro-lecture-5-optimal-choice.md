Solving optimality questions (the universal way):
![Worked example: u = x1 x2, income m = 8, prices p1 = 1, p2 = 2; substituting x1 = 8 - 2x2 gives u(x2) = x2(8 - 2x2), and du/dx2 = 8 - 4x2 = 0 yields x2* = 2, x1* = 4](../../assets/notes/year1/ff133e5b525f992e9f91.png)

Another method that works is to use the tangency condition to see if it yields an optimum. NOTE: this does not work if not convex etc.

![An optimum is either a corner point or an interior point; at an interior point MRS = -p1/p2 and the budget binds p1 x1 + p2 x2 = m. With convex preferences a point satisfying both conditions is guaranteed to be an optimum](../../assets/notes/year1/197096dd11ee2df62762.png)
